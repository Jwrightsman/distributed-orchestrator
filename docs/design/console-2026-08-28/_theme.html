Two deliberate changes from the old file: 1. --mark is the brand colour and is NEUTRAL, not green. Green is now reserved for status. 2. --radius drops from 8px to 5px (and 6px/12px to 4px/6px). Hairline tables at this density read as toy-like at 8px corners. FONTS: the stacks name IBM Plex first and fall back to system UI fonts. No webfont is loaded here on purpose — this project makes a point of not phoning home, and a Google Fonts on every page would be a request per visitor. To actually get Plex, self-host the woff2 files under static/ and add an @font-face block below. Without that the pages render in system fonts, which is a graceful and honest default. -->
