How it works

01

You pitch a task in plain English — “build a CSV deduplication script” — and say how you want it attempted.

02

It is split up, or attempted whole, depending on that choice. Only the planning strategy breaks work into pieces; the other two generate complete attempts and pick between them.

03

Invited machines do the building in parallel, each running an AI model locally. Every machine here belongs to someone who agreed to run it.

04

A reviewer assembles and grades the result, and the named checks run — it extracts, parses and imports. Whether it does what you asked is still yours to judge.

What it can and can't do

10/10

a labelled bar chart, built correctly ten times out of ten.

2/10

a playable Snake game. Tightly-coupled code is where a small model falls over, and that number is published for the same reason as the good one.

repro

every figure is reproducible from the repo, and the raw logs are committed alongside them.

Contributing a machine

Joining runs an AI model on your computer and uses spare CPU to build pieces of other people's tasks. The installer asks before it downloads or writes anything, and you stop it by closing the window. Joining is currently by invite — ask for an invite and you'll get the address and an invitation code.
