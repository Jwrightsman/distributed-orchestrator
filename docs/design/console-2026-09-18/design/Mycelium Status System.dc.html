01

The state machine

Four indicators derive their own truth today — the fail-open banner, the persistence-degraded banner, the locked screen and the footer's inference line. They can disagree, and three of the four have no idea whether the coordinator answered at all. One poller replaces them: four facets, each with three values, one severity, three renderings.

The failure this model exists to prevent

The dashboard on master paints its indicator from the last successful poll and never expires it, so a coordinator that died five minutes ago is still reported as connected. Green is therefore never a cached value here: a filled lamp requires a fresh confirmation, and the age of that confirmation is on screen at all times.

RULE · FACET DEPENDENCY

When link leaves up, every facet the coordinator serves becomes not-heard-back — never bad. A silent coordinator cannot tell you inference is down; saying it is would be inventing the answer. Only link: up plus an explicit negative is a confirmed bad.

RULE · SHAPE CARRIES THE THIRD VALUE

Filled square means a fresh answer; hollow square means no answer. Colour says which answer. So not-heard-back is never a colour that could be mistaken for good, and the state survives being filmed, printed, or read by someone who does not see green.

WHY THERE IS NO UTILIZATION GRAPH

A node's capability descriptor claims CPU count, physical memory and GPU at registration. Nothing measures them afterwards, and no endpoint serves a sample. A load line drawn from a claim is a drawing, not a measurement — so the bar carries counts and states, and the machine page carries the claim, labelled as claimed.
