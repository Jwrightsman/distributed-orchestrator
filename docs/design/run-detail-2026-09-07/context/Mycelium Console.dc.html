A CLIENT IS NOT A MACHINE
Every machine on this network has its own enrolment, so you can retire one and leave the rest working. Apps have nothing of the kind. They all present the same pitch_key, so the network cannot tell one from another, and there is one lever:
change pitch_key — cuts off every app at once
So hand it to people, not to services you would struggle to reach again. And the runs an app pitches land in Runs looking exactly like your own — the orchestrator does not record which door a pitch came through.
